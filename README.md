# 📊 Dashboard de RH - Power BI

Este repositório contém o meu primeiro dashboard interativo desenvolvido no Power BI. O objetivo do projeto foi praticar o ciclo completo de Business Intelligence na área de Recursos Humanos, transformando dados brutos em um painel executivo para tomada de decisão.

---

## 📌 Sobre o Projeto

O dashboard foi construído para analisar indicadores e métricas do setor de Recursos Humanos de forma visual e intuitiva. 

Etapas realizadas no projeto:
- Tratamento e estruturação da base de dados no Power Query.
- Construção do modelo de dados e relacionamentos entre tabelas.
- Criação de métricas com linguagem DAX.
- Elaboração do layout e combinação de componentes visuais para análise por filiais.

---

## 🛠️ Tecnologias Utilizadas

- **Power BI Desktop**
- **DAX (Data Analysis Expressions)**
- **Power Query**

---

## 🚀 Como Visualizar

1. Faça o download do arquivo `RH.pbix` presente neste repositório.
2. Abra o arquivo no **Power BI Desktop**.
3. Navegue pelos visuais e utilize os filtros para explorar as análises.
